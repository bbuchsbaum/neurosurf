# Map Values for NeuroSurface with Matrix Lookup

Map Values for NeuroSurface with Matrix Lookup

## Usage

``` r
# S4 method for class 'NeuroSurface,matrix'
map_values(x, lookup)
```

## Arguments

- x:

  a `NeuroSurface` object

- lookup:

  a `matrix` with two columns: the first column is the key, and the
  second column is the value
