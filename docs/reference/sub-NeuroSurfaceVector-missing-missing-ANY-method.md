# Extract All Data from NeuroSurfaceVector

Extracts all data from a NeuroSurfaceVector as a matrix.

## Usage

``` r
# S4 method for class 'NeuroSurfaceVector,missing,missing,ANY'
x[i, j, ..., drop = TRUE]
```

## Arguments

- x:

  the object

- i:

  first index

- j:

  second index

- ...:

  additional args

- drop:

  dimension

## Value

A numeric matrix containing all data
