# Subset NeuroSurfaceVector by Column

Extracts columns (time points) from a NeuroSurfaceVector.

## Usage

``` r
# S4 method for class 'NeuroSurfaceVector,missing,numeric,ANY'
x[i, j, ..., drop = TRUE]
```

## Arguments

- x:

  the object

- i:

  first index

- j:

  second index

- ...:

  additional args

- drop:

  dimension

## Value

A numeric matrix or vector of extracted column data
