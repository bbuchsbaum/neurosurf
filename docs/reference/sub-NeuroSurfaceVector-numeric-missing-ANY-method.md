# Subset NeuroSurfaceVector by Row

Extracts rows (vertices) from a NeuroSurfaceVector.

## Usage

``` r
# S4 method for class 'NeuroSurfaceVector,numeric,missing,ANY'
x[i, j, ..., drop = TRUE]
```

## Arguments

- x:

  the object

- i:

  first index

- j:

  second index

- ...:

  additional args

- drop:

  dimension

## Value

A numeric matrix or vector of extracted row data
