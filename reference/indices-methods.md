# Extract Vertex Indices

Extracts the vertex indices from surface objects.

## Usage

``` r
# S4 method for class 'ROISurface'
indices(x)

# S4 method for class 'ROISurfaceVector'
indices(x)

# S4 method for class 'NeuroSurfaceVector'
indices(x)

# S4 method for class 'NeuroSurface'
indices(x)
```

## Arguments

- x:

  the object to extract indices from

## Value

An integer vector of vertex indices
